Project Entities & Scope
Domain: Academic & Administrative School Management
Core Entities:
Student: Manages learner personal data, course registrations, and grade tracking.
Teacher: Manages staff profiles, course assignments, and grade entries.
Course: Defines academic subjects, credits, and details.
Enrollment: Acts as an association entity handling student-course registration records and statuses.
Modeling Tool: Draw.io
